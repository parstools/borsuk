# ToyC, ToyCP, and ToyScope projections

[English](PROJECTIONS.md) | [Polski](PROJECTIONS.pl.md)

Tracked `.sema` and `.ag` projections are generated by `coge` from authored
format 1 documents. Edit the source `.coge`, then regenerate the projections.

## File ownership

| Files | Owner and purpose |
| --- | --- |
| `coge/examples/toyc/toyc.coge`, `coge/examples/toycp/toycp.coge` | Authored grammar, analysis, and executor |
| `contracts/*-runtime-v1.json` | Explicit contracts for handwritten example runtimes |
| `coge/examples/*/generated/projections/*.sema` | Grammar and analysis, without execution |
| `*/examples/*/generated/projections/*.ag` | Grammar and lexer, without extensions |
| Adjacent `*.provenance.json` | Source/output hashes, contracts, and origin maps |
| `tests/fixtures/legacy/{toyc,toycp}_full.sema` | Independent legacy baselines for adapter and migration checks |
| `ag/grammars/examples/{toyc,toycp}.ag` | Independently maintained canonical Ag examples |
| `tests/fixtures/legacy/toyc.ag` | Legacy ToyC grammar copy |
| `coge/examples/{toyc,toycp}/generated/` | Generated Rust baselines |
| `sema/examples/toyscope_N/toyscope_N.coge`, N = 1, 2, 3 | Full ToyScope sources retaining execution contracts for conversion |
| Adjacent `toyscope_N.sema` and manifests | Clean generated analysis projections |
| `generated/projections/toyscope_N.ag` inside each ToyScope example | Grammar exports, without overwriting `tests/fixtures/legacy/toyscope.ag` |

Legacy `.sema` fixtures are not format 1 projections. `build/stage3-fixtures/`
contains temporary test output, not authored sources or baselines.

## Regeneration

From the repository root:

```sh
cmake --build build --target ag agas sema coge -j4
python3 tools/regenerate_examples.py toyc toycp
python3 tools/regenerate_examples.py toyscope_1 toyscope_2 toyscope_3
```

The script refreshes projections and Rust baselines. To refresh only ToyC/ToyCP
projections:

```sh
for language in toyc toycp; do
    build/bin/coge --force \
        --emit-sema "coge/examples/$language/generated/projections/$language.sema" \
        --contracts "contracts/$language-runtime-v1.json" \
        "coge/examples/$language/$language.coge"
    build/bin/coge --force \
        --emit-ag "coge/examples/$language/generated/projections/$language.ag" \
        "coge/examples/$language/$language.coge"
done
```

Each projection has its own `OUT.provenance.json`. It identifies the source,
output, and executed generator bytes. Rebuilding a binary can change
`tool_sha256` even when projection text is unchanged. `source` is a path
relative to the working directory used for export; its hash is the stronger
identity check.

Exports preserve the grammar projection law and check origin maps. Use the
projection and CLI tests alongside independent Rust behavior tests; provenance
alone does not prove semantic equivalence.
