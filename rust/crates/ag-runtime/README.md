# agas-runtime

`agas-runtime` is the small Rust execution layer for parsers generated by
Agas. It intentionally does not contain grammar analysis, LR/LALR table
construction, or C++ bindings. Those remain in Agas and Zbik.

The runtime executes validated, statically embedded Unicode lexer automata and
LR(k) tables. It supports the fast DFA path, priority-preserving ordered NFAs,
strict UTF-8, skipped rules, channels, byte ranges, full LR(k) lookahead and
resource limits. Its neutral AST layer executes the same nine reduction
opcodes as the C++ runtime and preserves payload spans separately from complete
recognized spans. This boundary lets Vist use the runtime without depending on
the Agas generator and allows this crate to move to a small independent
repository after its API stabilizes.

The `table_adapter` module converts a neutral AST produced by the generated
`CompressedTable` parser into an owned, validated LR table. It preserves row
sharing and distinguishes structural `EOF` from a terminal named `EOF`. Its
read-only view exposes ACTION and GOTO lookup only after validation. The
`artifact` module loads the complete version-1 package directory into owned,
validated models. It checks exact filenames, regular files, byte lengths,
SHA-256, canonical JSON, the parser DSL, resource limits and cross-section
references before returning a package. Optional diagnostics may include
validated production coverage metadata; older packages without that metadata
still parse normally. `LoadedPackage::parse` executes its lexer,
LR(k) table and neutral reductions through the same runtime used by static
parsers. The borrowed runtime views are built per call, so no package data is
leaked or copied into static storage. It returns the complete token stream and
either the neutral AST or a syntax error; lexical and resource-limit errors
remain distinct.

`agas_coverage` reads a package with production coverage metadata and parses
one explicit file or the `.vs` files in a directory. The `-r` option includes
subdirectories. It reports every source alternative and, for each parser
quantifier, the required `0`, `1`, and `2+` cases as applicable:

```bash
cargo run --bin agas_coverage -- [-r] ARTIFACT_DIR FILE_OR_DIRECTORY
```

An explicit file may have any extension. The command exits with status `1`
when parsing fails or coverage is incomplete.

`agas_ast_wire` emits a version-1 neutral AST JSON document for an accepted
source. Its exact source and symbol/AST catalog hashes bind the document to
the C++ consumer without a shared-language ABI. See
[`AST_WIRE_V1.md`](../../docs/AST_WIRE_V1.md) for the protocol and an
end-to-end command.

The Rust loader uses `serde_json` and `sha2`. It does not call C++, invoke the
Agas generator or require ANTLR. To load the checked-in package:

```rust
use agas_runtime::artifact::{load_package_directory, PackageLimits};
use std::path::Path;

let package = load_package_directory(
    Path::new("ag/artifacts/ag/v1"),
    PackageLimits::default(),
)?;
let source = std::fs::read("ag/grammars/Ag.ag")?;
let parsed = package.parse(&source, Default::default())?;
```

The checked-in parser data for `CompressedTable.ag` is reproduced without
ANTLR from the repository root:

```bash
build/bin/agas \
  --emit-rust-parser rust/crates/ag-runtime/src/generated/compressed_table.rs \
  ag/grammars/CompressedTable.ag
```

Run the Rust checks with:

```bash
cargo fmt --check
cargo test
cargo clippy --all-targets -- -D warnings
```
